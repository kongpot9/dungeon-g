# 🎨 그림 넣는 곳 (모든 그림 전부 여기! — 예준 확정)

캐릭터든 스킬이든 몬스터든 **모든 그림은 이 폴더에** 넣으면 돼.
png, jpg, PNG, JPG, jpeg, webp 다 됨.

**제일 쉬운 방법:** 그냥 IMG_1234.jpg 같은 이름 그대로 던져넣고 클로드한테
"그림 넣었어, 이건 OO 그림이야"라고 말하면 → 이름 바꾸기 + 배경 투명하게 만들기까지 클로드가 다 해줌!

## 넣는 방법

1. 그림 그리기 → 사진 찍기
2. 사진 파일을 이 폴더에 복사
3. 파일 이름을 위 표대로 바꾸기 (예: `IMG_1234.jpg` → `slime.jpg`)
4. 게임 새로고침 → 짠! 등장

그림이 없으면 임시 그림(초록 젤리, 번개)이 나와. 하나씩 넣어도 돼!
