# 🎵 소리 넣는 곳

여기에 소리 파일을 넣고 **이름만 맞추면** 게임에 자동으로 나와!
(그림이랑 똑같은 방식 — 파일이 있으면 그걸 쓰고, 없으면 기본 합성음)

**되는 파일 형식**: mp3, wav, m4a, ogg
(폰으로 녹음하면 보통 m4a나 mp3야. 그대로 넣으면 됨)

## 파일 이름

| 파일 이름 | 언제 나는 소리? | 추천 |
|---|---|---|
| `hit` | ⚔️ 평타 때릴 때 | 짧게! "퍽" (0.2초 이내) |
| `crit` | 💥 크리티컬·변신 공격 | 더 쎈 "쾅!" |
| `hurt` | 아군이 맞을 때 | "윽" |
| `tick` | 🎰 뽑기 두구두구 (반복됨) | **아주 짧게** "딱" (0.1초) |
| `legend` | ⭐ 전설 뽑았을 때 | 길어도 됨 "두두둥탁!" (2초까지) |
| `transform` | 🐉 드래베오 변신 | "크아아앙!" |
| `win` | 🎉 클리어 | "굳!" / 팡파레 |
| `lose` | 💀 전멸 | "아아..." |
| `stun` | 💫 스턴 걸었을 때 | "삐용" |
| `reward` | 🎁 보상 받을 때 | "짠!" |
| `click` | 🔘 버튼 누를 때 | 아주 짧게 "톡" |

## 소리 만드는 법 (쉬운 순서)

### 1. 🎤 목소리 녹음 — 제일 쉽고 제일 웃김
폰 녹음기 앱으로 그냥 입으로 소리 내면 끝.
던전G는 병맛 게임이라 **이게 제일 잘 어울려.**

> 팁: 조용한 방에서, 마이크에 너무 가까이 대지 말고, **앞뒤 조용한 부분은 잘라내기**

### 2. 🎮 게임 효과음 만드는 웹사이트
"jsfxr" 또는 "sfxr" 로 검색하면 나오는 사이트에서
버튼 몇 번 누르면 게임 효과음이 자동으로 만들어지고 다운로드도 돼. (무료)

### 3. 🥁 실제 물건 소리 녹음
책상 두드리기 = 타격음, 종이 구기기 = 바스락, 냄비 = 쾅
진짜 게임 회사도 이렇게 만들어! (폴리 사운드라고 함)

## 주의

- **짧게!** 특히 `hit`, `tick`, `click`은 짧아야 안 답답해
- 너무 시끄럽게 녹음하면 찢어지는 소리가 나. 적당히
- 파일 이름은 위 표대로 (확장자는 아무거나)
